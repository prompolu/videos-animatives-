Sur GitHub, ouvrez le fichier vidéo puis utilisez **Download raw file** (icône de téléchargement) pour enregistrer le MP4. Le ZIP contient le MP4 musical, les deux CSV et le storyboard ; la vidéo silencieuse se télécharge séparément.

Le montage comprend sept catégories et 86 sections. Il conserve les 503 mentions du relevé officiel précédent ; six apparitions supplémentaires représentent des appartenances à plusieurs sous-catégories. Les photographies officielles disponibles illustrent les produits ; les noms sans photographie documentée restent présentés sous forme typographique. Les statistiques du relevé ne sont pas un décompte de SKU uniques. Le message de l’entreprise « Plus de 320 produits » reste affiché.

La hiérarchie détaillée et les preuves de classement sont conservées dans `hierarchy.json`. Les originaux fournis sont dans `../../assets/user/`, la musique dans `../../assets/saraproc-ambient-loop.wav` et le brief dans `../../creative/brief-hierarchique-fr.md`.
